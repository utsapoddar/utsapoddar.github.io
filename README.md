# utsapoddar.github.io

Source for my personal portfolio site, served by GitHub Pages at
**[utsapoddar.github.io](https://utsapoddar.github.io)**.

Hand-written HTML, CSS, and vanilla JavaScript — no framework and no build step. The only
external dependency is the Inter webfont. Pushing to the default branch deploys.

| File | Purpose |
|---|---|
| `index.html` | Page structure and content |
| `style.css` | Layout and typography |
| `bg.css`, `bg.jpg` | Background treatment |
| `script.js` | Interaction |

## Local preview

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```
